# ruri-patch 🎀

An unofficial kawaii patcher for the `anthropic.claude-code` VS Code extension.
Replaces the spinner phrases, thinking phases, logo and Claude name with Ruri —
plus pink outlines, ambient background FX and a hopping mascot.

Run `replace_with_uwu.sh` after each extension update (patches break on updates,
re-run to re-apply).

For personal use — modifies your locally installed extension. Not affiliated
with or endorsed by Anthropic. 💖

Want the agent to *talk* like Ruri too? Grab [ruri-agent](https://github.com/genius257/ruri-agent/).
